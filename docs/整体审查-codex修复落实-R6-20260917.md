## 2. 复核中发现并一并修复

- Windows 下，拒绝 POST 时关闭仍有未读请求体的连接会偶发 RST，导致客户端收不到 JSON 错误。拒绝路径对正常、有长度且不超过 256 KiB 的请求体做限时读取；不解析或执行业务，随后返回 403/415。
- DSH 的来源重写原先按原始 Host 字符串比较，与入口对大小写和默认端口的规范化不一致。两处共用来源解析规则；增加实际 HTTP 及双向 WebSocket 帧回归。
- 浏览器检查发现候选预览增加选择器后，在小窗口及较大文字下保存按钮落到对话框滚动区下方。仅调整 Python 编辑器的弹性布局和窄屏按钮排列，源码在独立编辑区滚动，保存操作保持可见。
- 独立交叉复核覆盖 HTTP/DSH 来源链路、脚本候选/草稿/选择代际与迟到响应。上述问题修复后，本次复核范围内未发现待处理的确定缺陷。

## 4. 验证边界

- 来源检查不是登录鉴权；服务仍面向可信 LAN。Python 脚本、插件适配器及本机 AI 使用服务账户的权限；AST 和只读数据库连接不等于操作系统沙箱。
- 操作系统拒绝 taskkill 时，日志会提供原因，fallback 只终止可终止的父进程；不能据此保证无权限终止的全部后代已经退出。
- 本轮没有真实内网模型端点、业务 EXE/DLL、OpenCppCoverage 和正式全量数据，因此未将本机模型 fixture 或模拟任务称为正式业务验收。
- Windows x64 内网编译机仍需 VS2022 C++、Windows SDK、CMake。已存在的离线 Python 与 DSH 材料继续提供。
