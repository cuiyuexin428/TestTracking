# 界面闭环验收与离线交付（2026-09-20）

范围：`codex/deployment-automation` 当前工作区，接续《部署向导与插件安装验证》。本轮用浏览器实际操作验证任务、进度、客户端、日志、数据库报告和客户端制品发布，并落实发现的问题。交付版本为 0.4.0，保持单客户端单插件和仅 DSH 的范围。

## 本轮修复

1. **制品程序切换成本机路径时残留旧身份。** 向导现在清除原自动生成的程序版本，回到本机版本读取方式；STP 明确手填的新版本保留。不再引用的原制品槽位会移除，共享依赖和未知配置继续保留。再次预览不会自动选回旧制品。
2. **重复任务只显示英文错误。** 调度器原有重复任务字段被 Python 代理丢弃，导致前端无法识别已有运行。现仅透传明确重复响应中的运行编号、状态和强制重跑标志，页面区分已完成、执行中和排队状态。通用错误行为不变，未知内部字段不透传。
3. **交付材料遗漏。** 源码 ZIP 排除临时 `runtime/deployment_ui_review`，仍保留业务源码和离线依赖。服务端包新增三份使用文档，并更新包内 README 的自动部署、插件安装和手动重启说明。
