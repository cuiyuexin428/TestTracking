# 插件与部署界面改版验收（2026-09-21）

## 1. 本轮范围

本轮调整“插件与配置”页面的信息结构、视觉布局和操作流程，并将入口改为“插件与部署”。变更范围为网页 HTML、CSS、JavaScript，以及对应测试和文档；任务调度、客户端协议、数据库结构和服务端 API 保持原有实现。

主要改动：

- 将页面分为“插件、制品库、客户端部署、服务配置”四个页签，切换页签保留当前编辑草稿。
- 客户端部署采用五步流程：选择客户端、选择插件、程序与数据、运行安排、确认发布。按步骤校验输入，进入确认前生成部署预览，发布期间避免重复提交和目标切换。
- 制品库增加搜索和类型筛选；插件、制品、部署详情按需放入侧边抽屉，支持关闭后恢复焦点。
- 服务配置优先展示常用字段，完整 JSON、字段说明和生效值放入高级配置。表单修改保留未知字段和密钥占位符。
- 收敛按钮、表单和表格的视觉层级，减少默认展开的技术细节；布局随主内容区域宽度调整，并兼容右侧 AI 面板占用的空间。

保留单客户端单插件、执行与结果分析分离、独立执行和更新时间窗，以及服务端程序匹配配置与客户端部署分别保存的原有约定。
